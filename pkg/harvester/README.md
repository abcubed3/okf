# `harvester`

## Overview
Package `harvester` extracts structured Open Knowledge Format (OKF) concepts (`*bundle.Concept`) from external technical systems and persists them as frontmatter-annotated Markdown files. It defines a common `Harvester` interface along with concrete extractors for relational/analytical databases (`DBHarvester` with BigQuery, MySQL, PostgreSQL, and Cloud Spanner `SchemaProvider` adapters), Git repositories (`GitHarvester`), OpenAPI/Swagger v2 & v3 specifications (`OpenAPIHarvester`), Protobuf schemas (`ProtobufHarvester`), and web documentation sites (`WebHarvester` with optional Gemini `LLMClassifier` metadata enrichment).

## Interface
- `[harvester.go:Harvester]` — `type Harvester interface`: Defines `Harvest(ctx context.Context) ([]*bundle.Concept, error)`.
- `[harvester.go:WriteConcepts]` — `func WriteConcepts(concepts []*bundle.Concept, outputDir string) error`: Concurrently serializes harvested concepts to Markdown files with YAML frontmatter under `outputDir`.
- `[db.go:SchemaProvider]` — `type SchemaProvider interface`: Defines `GetTables(ctx context.Context) ([]TableMetadata, error)`, `GetColumns(ctx context.Context, tableName string) ([]ColumnMetadata, error)`, `GetForeignKeys(ctx context.Context) ([]ForeignKeyMetadata, error)`, and `TypeString() string`.
- `[db.go:TableMetadata]`, `[db.go:ColumnMetadata]`, `[db.go:ForeignKeyMetadata]` — Schema metadata structs returned by `SchemaProvider` implementations.
- `[db.go:DBHarvester]` & `[db.go:NewDBHarvester]` — `type DBHarvester struct { Provider SchemaProvider }`, `func NewDBHarvester(provider SchemaProvider) *DBHarvester`, and `(h *DBHarvester) Harvest(ctx context.Context) ([]*bundle.Concept, error)`.
- `[db_bigquery.go:BigQueryProvider]` & `[db_bigquery.go:NewBigQueryProvider]` — `type BigQueryProvider struct { Client *bigquery.Client; Dataset string }` and constructor `NewBigQueryProvider(client *bigquery.Client, dataset string) *BigQueryProvider` implementing `SchemaProvider`.
- `[db_mysql.go:MySQLProvider]` & `[db_mysql.go:NewMySQLProvider]` — `type MySQLProvider struct { DB *sql.DB; Schema string }` and constructor `NewMySQLProvider(db *sql.DB, schema string) *MySQLProvider` implementing `SchemaProvider`.
- `[db_postgres.go:PostgresProvider]` & `[db_postgres.go:NewPostgresProvider]` — `type PostgresProvider struct { DB *sql.DB; Schema string }` and constructor `NewPostgresProvider(db *sql.DB, schema string) *PostgresProvider` implementing `SchemaProvider`.
- `[db_spanner.go:SpannerProvider]` & `[db_spanner.go:NewSpannerProvider]` — `type SpannerProvider struct { DB *sql.DB }` and constructor `NewSpannerProvider(db *sql.DB) *SpannerProvider` implementing `SchemaProvider`.
- `[git_harvester.go:GitHarvester]` & `[git_harvester.go:NewGitHarvester]` — `type GitHarvester struct`, `func NewGitHarvester(repoPath string) *GitHarvester`, and `(gh *GitHarvester) Harvest(ctx context.Context) ([]*bundle.Concept, error)`.
- `[llm.go:LLMClassifier]` & `[llm.go:NewLLMClassifier]` — `type LLMClassifier struct`, `func NewLLMClassifier(ctx context.Context, apiKey string) (*LLMClassifier, error)`, `(c *LLMClassifier) Classify(ctx context.Context, title, body string) (bundle.Frontmatter, error)`, and `(c *LLMClassifier) Close() error`.
- `[openapi.go:OpenAPIHarvester]` & `[openapi.go:NewOpenAPIHarvester]` — `type OpenAPIHarvester struct { SpecPath string }`, `func NewOpenAPIHarvester(specPath string) *OpenAPIHarvester`, and `(h *OpenAPIHarvester) Harvest(ctx context.Context) ([]*bundle.Concept, error)`.
- `[protobuf.go:ProtobufHarvester]` & `[protobuf.go:NewProtobufHarvester]` — `type ProtobufHarvester struct { Path string }`, `func NewProtobufHarvester(path string) *ProtobufHarvester`, and `(h *ProtobufHarvester) Harvest(ctx context.Context) ([]*bundle.Concept, error)`.
- `[web.go:WebHarvester]` & `[web.go:NewWebHarvester]` — `type WebHarvester struct`, `func NewWebHarvester(startURL string, maxDepth int, llm *LLMClassifier) *WebHarvester`, and `(h *WebHarvester) Harvest(ctx context.Context) ([]*bundle.Concept, error)`.

## Invariants
- `[harvester.go:WriteConcepts]` — Enforces path-containment under `absOutputDir` (`strings.HasPrefix(targetPath, absOutputDir+string(os.PathSeparator))`), defaults unset `Frontmatter.Generated` to `&bundle.ActorInfo{By: "okf-harvester", At: RFC3339}` and unset `Frontmatter.Status` to `bundle.ConceptLifecycleStable`, and wraps YAML frontmatter in `---\n` delimiters.
- `[db.go:DBHarvester.buildTableConcept]` — Emits table concepts at ID `tables/<lower(table.Name)>` (`Path: tables/<lower(table.Name)>.md`, `Type: "<TypeString()> Table"`), renders empty `DefaultVal` as `NULL` and empty `Description` as `-`, and omits `## Key Relationships` when no outgoing or incoming foreign keys exist.
- `[db_bigquery.go:BigQueryProvider.GetTables]` & `[db_bigquery.go:BigQueryProvider.GetColumns]` — Filters BigQuery dataset tables to `meta.Type == bigquery.RegularTable`, formats repeated columns as `ARRAY<<Type>>`, sets `IsNullable = !field.Required`, and always returns `(nil, nil)` from `[db_bigquery.go:BigQueryProvider.GetForeignKeys]`.
- `[db_mysql.go:MySQLProvider.resolveSchema]` & `[db_mysql.go:MySQLProvider.GetTables]` — Resolves empty `Schema` via `SELECT DATABASE()` (returning an error if `NULL` or empty) and filters `information_schema.tables` to `table_type = 'BASE TABLE'`.
- `[db_postgres.go:NewPostgresProvider]` & `[db_postgres.go:PostgresProvider.GetTables]` — Defaults empty `schema` to `"public"` and filters `information_schema.tables` to `table_type = 'BASE TABLE'`.
- `[db_spanner.go:SpannerProvider.GetTables]`, `[db_spanner.go:SpannerProvider.GetColumns]`, & `[db_spanner.go:SpannerProvider.GetForeignKeys]` — Queries only the default user schema (`table_schema = ''` in `GetTables` and `GetColumns`, and `rc.constraint_schema = ''` in `GetForeignKeys`), filters `GetTables` to `table_type = 'BASE TABLE'`, and records interleaved hierarchy (`parent_table_name`) as `"Interleaved parent table: <parent_table>."`.
- `[git_harvester.go:GitHarvester.Harvest]` & `[git_harvester.go:slugifyEmail]` — Always emits a `git/repository` summary concept, caps `git/commits/<8-char-hash>` concepts at the 15 most recent commits from `HEAD` (and per-commit file diffs at 30 files), and aggregates `git/contributors/<slug>` concepts keyed by lowercased trimmed non-empty author email (`@` -> `-at-`, `.` and `_` -> `-`).
- `[llm.go:NewLLMClassifier]` & `[llm.go:LLMClassifier.Classify]` — Configures Gemini model `"gemini-1.5-flash"` with `ResponseMIMEType: "application/json"` and required schema fields `type`, `title`, and `description`; truncates `body` inputs exceeding 4,000 bytes (`body[:4000]`) prior to inference.
- `[openapi.go:OpenAPIHarvester.Harvest]` & `[openapi.go:OpenAPIHarvester.buildEndpointConcept]` — Auto-converts Swagger v2 (`"swagger":` / `swagger:`) to OpenAPI v3, iterates sorted paths and fixed HTTP method order (`GET`, `POST`, `PUT`, `DELETE`, `PATCH`, `OPTIONS`, `HEAD`) to emit `endpoints/<method>-<normalizedPath>` concepts, and truncates frontmatter descriptions exceeding 100 runes to 97 runes plus `"..."`.
- `[protobuf.go:ProtobufHarvester.Harvest]` & `[protobuf.go:ProtobufHarvester.extractConcepts]` — Returns `(nil, nil)` when a directory contains zero `.proto` files; recursively extracts top-level and nested messages (`Protobuf Message`) and services (`Protobuf Service`) under `protobuf/<lowercased-fqn>`, truncating frontmatter descriptions exceeding 100 runes to 97 runes plus `"..."`.
- `[web.go:WebHarvester.Harvest]` — Restricts crawling to `parsedURL.Host` and `maxDepth` (async parallelism `2`, `500ms` delay), strips `script, style, nav, footer, header, aside, .sidebar` elements before Markdown conversion, falls back to `Type: "Documentation"` when `llm` is `nil` or classification fails, and synchronizes `concepts` slice appends with a `sync.Mutex`.

## Side Effects
- `[harvester.go:WriteConcepts]` — Mutates `Frontmatter.Generated` and `Frontmatter.Status` in place on input `*bundle.Concept` pointers when unset, creates directories on disk (`0755`), and concurrently writes/overwrites `.md` files (`0644`) via `errgroup.Group`.
- `[db.go:DBHarvester.Harvest]`, `[db_bigquery.go:BigQueryProvider.GetTables]`, `[db_mysql.go:MySQLProvider.GetTables]`, `[db_postgres.go:PostgresProvider.GetTables]`, `[db_spanner.go:SpannerProvider.GetTables]` — Executes outbound BigQuery API RPCs or SQL metadata queries against `information_schema` / `pg_catalog` via `*bigquery.Client` or `*sql.DB`.
- `[git_harvester.go:GitHarvester.Harvest]`, `[openapi.go:OpenAPIHarvester.Harvest]`, `[protobuf.go:ProtobufHarvester.Harvest]` — Reads local Git object stores (`git.PlainOpen`), OpenAPI spec files (`os.ReadFile`, `openapi3.NewLoader().LoadFromFile`), and `.proto` source trees (`filepath.Walk`, `protocompile.SourceResolver`) from disk.
- `[llm.go:NewLLMClassifier]` & `[llm.go:LLMClassifier.Classify]` — Initializes a `genai.Client` connection and issues outbound network requests to the Google Gemini API (`gemini-1.5-flash`).
- `[web.go:WebHarvester.Harvest]` — Issues concurrent outbound HTTP/HTTPS requests via `colly.Collector`, optionally calls `LLMClassifier.Classify`, and prints crawl status and errors to stdout via `fmt.Printf`.
